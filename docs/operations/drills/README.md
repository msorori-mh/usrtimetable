# أدلة تمارين الاستعادة

يكتب `scripts/local-db/backup-restore-drill.sh` هنا ملفًا `restore-drill-<UTC>.txt` بعد كل تمرين ناجح
(التسمية، المخططات، عدد الجداول والصفوف لكل جدول، الأزمنة، commit). لا تحتوي الملفات على روابط
أو أسماء مستخدمين أو بيانات. أضف كل ملف دليل في commit مستقل. لم يُنفَّذ أي تمرين على بيانات
حقيقية بعد — أول تمرين ربع سنوي مطلوب (انظر `../supabase-backup-restore.md`).
