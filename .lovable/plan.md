# توحيد مصطلح المحاضرة

## الهدف
توحيد النص العربي المواجه للمستخدم بحيث تُسمى مكونات المقرر الأكاديمية «محاضرات» وأنواعها «أنواع المحاضرات»، دون تغيير أي اسم أو قيمة تقنية.

## التنفيذ
- تحديث صفحات الإدارة والنوافذ والفلاتر والجداول والتنبيهات والجاهزية والتقارير والطباعة إلى الصياغة العربية الصحيحة بحسب السياق: «المحاضرة»، «نوع المحاضرة»، «ساعات المحاضرة»، و«محاضرات المقرر/الخطة».
- تحديث رسائل التحقق والتصدير وقوالب Excel وتعليماتها إلى العناوين الجديدة مثل `نوع_المحاضرة` و`ساعات_المحاضرة_المسندة`.
- إضافة أسماء بديلة صريحة في عقد الاستيراد تقبل العناوين القديمة والجديدة، وتوحيدها قبل فحص الأعمدة والتكرار وتحويل الصفوف.
- تحديث الوثائق التشغيلية والاختبارات المرتبطة مباشرة بالواجهة والاستيراد والطباعة، مع إبقاء «مكوّنات المنصّة» والسياقات البرمجية العامة في قائمة سماح محدودة.
- عدم تعديل قاعدة البيانات أو migrations أو الأنواع المولدة أو الحقول والقيم التقنية أو المنطق الأكاديمي والجدولة.

## التحقق
- حفظ جرد قبل/بعد بعدد الأسطر والملفات المتأثرة، وإضافة اختبار nomenclature/contract يمنع بقاء المصطلحات القديمة في المسارات المحددة إلا لقائمة السماح.
- اختبار أن قالب Excel الجديد يصدر العناوين الجديدة، وأن ملفات العناوين القديمة والجديدة تُستورد إلى المفاتيح التقنية نفسها، بما فيها كشف وضع ملف الإسناد الرسمي.
- تشغيل الاختبارات المركزة، ثم typecheck وESLint والبناء، وفحص نظافة التغييرات وحصر عدد الملفات والنصوص المعدلة والـcommit النهائي.
