# إضافة البرنامج ونظام الدراسة إلى صفوف الإسناد

## التنفيذ
- قراءة أسماء البرامج وسياق جميع الدفعات في الكلية للعرض فقط، مع استخدام روابط المحاضرات المشتركة الموجودة.
- اشتقاق اسم البرنامج ونظام الدراسة من دفعة كل صف، وتجميع البرامج والأنظمة المشاركة للمجموعات المشتركة دون الاكتفاء بالدفعة الأساسية.
- إضافة عمودي «البرنامج» و«نظام الدراسة» بجوار «المقرر» في جدول الإسناد، مع عرض «عام» و«موازي» بالقيم العربية المختصرة.

## التحقق
- إضافة اختبارات منطقية لحالة صف عادي وصف مشترك متعدد البرامج، واختبار ربط العمودين بالجدول.
- تشغيل الاختبارات المركزة وTypeScript وESLint والبناء وفحص فرق الملفات.

## الحدود
- لا تعديل لقاعدة البيانات أو الإسنادات أو الفلاتر أو الصلاحيات أو الجدولة، ولا نشر.
