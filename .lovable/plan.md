# تحسين RTL وتقرير القاعات التحليلي

## 1. توحيد RTL في المحددات
- استكمال ضبط مكونات Select وDropdown وCommand/Combobox المشتركة بحيث تكون النصوص والقيم والبدائل والعناصر عربية الاتجاه ومحاذاة لليمين، مع مواضع صحيحة للسهم وعلامة الاختيار.
- إضافة اختبار انحدار لمحدد الكلية في التقارير، ومراجعة محددات المقررات والمحاضرين والقاعات والبرامج والأقسام التي ترث المكونات المشتركة.

## 2. حسابات تقرير القاعات
- توسيع المنطق النقي الحالي ليحسب لكل مورد: المستخدم والمتاح والفارغ والتجاوز، استغلال الوقت، عدد الجلسات، متوسط/أعلى الطلاب، متوسط/أعلى ملء السعة، ذروة اليوم والفترة، وتقسيم أنواع الجلسات.
- إبقاء `room_availability` المصدر الأول للساعات المتاحة مع fallback لإعدادات الدوام، واستخدام جلسات النسخة المختارة فقط و`expected_students` الحالي.
- تصنيف الموارد من نوع الغرفة الفعلي إلى قاعات نظرية ومعامل، وحساب الملخص التنفيذي والفئات وأعلى/أقل خمسة وخريطة الحرارة والاستنتاج الوصفي.

## 3. واجهة التقرير
- إضافة ملخص تنفيذي واضح، وفصل عرض الكل/القاعات/المعامل، وفلاتر الازدحام والنوع، وفرز حسب الاستغلال والفارغ والسعة والجلسات.
- إضافة رسوم Recharts: ترتيب الاستغلال، المستخدم مقابل الفارغ، حلقة الإجمالي، ومقارنة القاعات بالمعامل؛ وبناء heatmap عربية عبر CSS Grid.
- عرض القيم نصيًا بجانب الرسوم، وإضافة قائمة تكشف الاستغلال الزمني العالي مع ملء سعة منخفض عند وجودها.
- إبقاء جدول التفاصيل قابلًا للتوسيع مع تمرير أفقي على الشاشات الصغيرة، وتحسين صفحات كل قاعة الأسبوعية ببياناتها والفترات الفارغة الممكنة.

## 4. الطباعة والتصدير
- جعل أول صفحات A3 الأفقية تعرض الرأس الرسمي والملخص وأهم الرسوم، ثم جدول الملخص، ثم صفحات القاعات الحالية دون إسقاط أي جلسة أو مورد.
- استخدام SVG القابل للطباعة، وحد أقصى رسمين في الصفحة، مع قواعد تمنع القص؛ وتوسيع أعمدة Excel/CSV لتطابق التحليل.

## 5. التحقق والنشر
- إضافة اختبارات pure للحسابات والفئات والقمم وأعلى/أقل خمسة وheatmap، وregression لمطابقة ساعات النسخة وعدم سقوط جلسات التجميع.
- اختبار بنية الشاشة والطباعة، ثم تشغيل Prettier وESLint المحدد وtypecheck والاختبارات المركزة والبناء و`git diff --check`.
- بعد PASS: نشر النسخة وإرجاع الحالة والاختبارات والملفات والـcommit والحدود المتبقية.

## حدود ثابتة
- تغيير عرض وتحليل للقراءة فقط؛ لا تعديل للبيانات أو الصلاحيات أو المخطط أو الجدول أو الإسنادات، ولا إنشاء نسخة أو تشغيل المجدول.
