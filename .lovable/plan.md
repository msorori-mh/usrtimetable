# PRINT-HEADER-05

## الهدف
إعادة تنسيق رأس الجدول العربي المشترك ليصبح مضغوطاً ومهنياً، مع الحفاظ على كل البيانات وسلوك الطباعة السابق.

## التنفيذ
- إعادة بناء رأس `PrintSheet` إلى شريط هوية ثلاثي: شعار وهوية الجامعة يميناً، عنوان الجدول في الوسط، ورمز التحقق يساراً.
- توزيع القسم/البرنامج، المستوى/النظام، والفصل/العام في شبكة حقول واضحة ومتوازنة، ثم صف بيانات إصدار صغير وهادئ.
- إضافة أنماط دلالية مشتركة متجاوبة للشاشة والطباعة، بألوان كحلية محدودة ومتوافقة مع التدرج الرمادي، والتفاف آمن للأسماء العربية الطويلة.
- عدم تغيير محتوى QR أو الحقول الاختيارية أو عناوين مجموعات الجداول أو الأعمدة والصفوف أو منطق البيانات والصلاحيات.

## الإثبات
- توسيع full-shell fixture ببيانات وصفية عربية طويلة وفحوص بنية الرأس وعدم القص.
- تشغيل مجموعة الحالات الحالية كاملة: A4/A3، طولي/عرضي، جوال/سطح مكتب، بيانات قصيرة/طويلة.
- إنتاج PDF وصور PNG مستقلة ومراجعة صورة مطبوعة فعلياً، مع إبقاء إصلاحات shell السابقة.
- إضافة اختبارات انحدار مركزة، وتشغيل typecheck والاختبارات ذات الصلة وbuild.
- توثيق النتائج وقائمة الملفات الدقيقة ومسارات ملفات الإثبات في `docs/PRINT-HEADER-05.md`، دون نشر.
