# تصحيح ترتيب صفحة الإدارة العليا في الإنتاج

## التنفيذ
- تثبيت بنية واحدة صريحة داخل المكوّن الفعلي: المؤشرات العلوية، ثم صف البطاقات الثلاث، ثم مقارنة الكليات.
- إضافة معرّفات بنيوية للصف والبطاقات وقسم المقارنة، مع `dir="rtl"` وترتيب DOM نفسه للجوال وسطح المكتب، دون تكرار أو تغيير المحتوى والبيانات.
- استبدال اختبار ترتيب النص في الملف باختبار بنيوي يفحص حدود العقد وترتيبها وغياب أي أصناف تعيد الترتيب بصريًا.

## التحقق والنشر
- تشغيل اختبارات القيادة والصلاحيات، وفحص TypeScript والبناء.
- فحص الصفحة محليًا على سطح المكتب والجوال.
- نشر النسخة، ثم إعادة تحميل إنتاجية كاملة والتحقق من ترتيب عقد DOM الفعلية قبل إعلان PASS.

## خارج النطاق
- لا تغييرات بيانات أو قاعدة بيانات أو صلاحيات أو migrations.
